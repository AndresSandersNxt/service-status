# The People Panel brand assets

These assets come from the supplied `Website The People Panel_Aflevermap` design package.

- `people-panel-logo.svg`: original vector wordmark extracted from the header on page 2 of `The People Panel_Website_Low.pdf`.
- `../favicon.svg`: the original symbol from that wordmark, with a white background to remain visible in light and dark browser tabs.
- `fonts/`: the supplied Cambon SemiBold font, converted to WOFF2 for local web delivery.

The page uses the first PDF page's black (`#000000`) and coral (`#ff616e`) palette and Cambon headings. Service information uses a system sans-serif font with larger labels for legibility. Darker coral is used for text on light backgrounds to preserve readable contrast. Green and amber communicate service availability.
